# 프로젝트 설정 기본값

프로젝트 저장소의 AGENTS.md에 "프로젝트 설정" 절이 있으면 그 값이 우선한다. 없으면 아래 기본값을 쓰고, 비어 있는 명령·개인별 선택은 추정하지 않는다. 프로젝트별 값과 개인 설정은 프로젝트 AGENTS.md의 프로젝트 설정 절 또는 사용자 로컬 설정에만 기록한다.

| 항목                                       | 값                                                                       |
| ------------------------------------------ | ------------------------------------------------------------------------ |
| 현재 명세(Baseline)                        | `docs/spec/current/`                                                     |
| 작업별 문서                                | `docs/changes/<작업ID>/` (spec·design·tasks·handoff·impl-report·verdict) |
| 결정 기록                                  | `docs/decisions/`                                                        |
| 전역 구조                                  | `docs/ARCHITECTURE.md` (필요할 때 만든다)                                |
| 수락 시험 위치                             | `tests/acceptance/`                                                      |
| 기획설계의 수락 시험 쓰기 허가             | 허용 <!-- 허용 / 불허 -->                                                |
| 사전 위임 범위(경미 작업 사용자 확인 생략) | 없음 <!-- 예: 문서 오탈자, 주석, 로그 문구 -->                           |
| ID 발급 방식                               | 작업 ID 접두어 <!-- 예: RW-12 작업의 요구는 REQ-RW12-01 -->              |
| 빌드 명령                                  | <!-- 채운다 -->                                                          |
| 시험 명령                                  | <!-- 채운다 -->                                                          |
| 정적 분석 명령                             | <!-- 채운다 -->                                                          |
| 건드리면 안 되는 경로                      | <!-- 채운다 -->                                                          |
| 위험 정책 위치                             | 없음(`00-common.md` 4절 사용)                                            |
| 규제 대상 여부                             | 아니오 <!-- 예이면 00-common.md 9절 적용 -->                             |
| 기본 진행 방식                             | 연합개발                                                                 |
| 일반개발 기본 담당                         | <!-- 예: Claude Code / 모델 / 추론 강도 -->                              |
